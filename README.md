# Restaurant Management System

A full-stack Restaurant Management System built with Angular, Spring Boot, and Oracle Database. Features secure JWT authentication, role-based access control, product, category, order, customer, and chef management. Designed with RESTful APIs, responsive UI, data validation, pagination, and clean architecture principles.

## 🚀 Features

- JWT Authentication & Authorization
- Role-Based Access Control (Admin, Customer, Chef)
- Product Management
- Category Management
- Order Management
- Customer Management
- Customer Profile Management
- Chef Management
- Contact Information Management
- Pagination & Validation
- Responsive User Interface
- RESTful API Integration
